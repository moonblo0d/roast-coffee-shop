# ROAST — інтернет-магазин кави з замовленнями в Telegram

Демо-магазин свіжообсмаженої кави (бізнес вигаданий): каталог, кошик, оформлення з доставкою Новою Поштою.
Замовлення зберігаються в SQLite, власник миттєво отримує їх у Telegram і керує статусами кнопками,
а в адмінці бачить виручку, середній чек і топ товарів.

**Вітрина наживо:** https://moonblo0d.github.io/roast-coffee-shop/ (на GitHub Pages оформлення працює в демо-режимі)

## Можливості

**Вітрина (`docs/`)**
- каталог із фільтрами за обсмаженням і способом заварювання, пошук за країною та смаковими нотами, сортування;
- вибір помелу для кожного товару, кошик-шухляда з кількістю, збереження в `localStorage`;
- прогрес до безкоштовної доставки, підрахунок доставки й підсумку;
- оформлення: ім'я, телефон, місто, відділення НП, оплата карткою або накладеним платежем, валідація;
- ілюстрації пакетів — згенерований SVG, без жодної картинки; адаптив під телефон.

**Сервер**
- `POST /api/orders` — **перераховує суму за цінами з каталогу на сервері** (ціни від клієнта ігноруються), валідація, антиспам;
- сповіщення адміну в Telegram у фоні — покупець не чекає відповіді Telegram;
- статуси: Нове → Підтверджено → Відправлено → Отримано / Скасовано.

**Telegram-бот**
- адмін: картка кожного замовлення з кнопками статусів, `/orders`, `/stats` (виручка, середній чек, топ-3 товари);
- клієнт: `/status` — перевірка статусу за номером замовлення + останні 4 цифри телефону.

**Адмінка `/admin`** (пароль): KPI, графік за статусами, фільтри, зміна статусу, автооновлення.

## Стек
Python · aiogram 3 · aiohttp · SQLite · HTML / CSS / JavaScript без фреймворків.

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # Linux/macOS: cp .env.example .env
python main.py
```
У `.env`: `BOT_TOKEN` (від @BotFather), `ADMIN_CHAT_ID` (ваш Telegram ID), `PANEL_PASSWORD`.
Магазин: http://127.0.0.1:8081/ · адмінка: http://127.0.0.1:8081/admin (логін `admin`).

## Структура
```
main.py     — запуск сайту й бота
web.py      — API замовлень, перерахунок кошика, адмін-API
bot.py      — сповіщення, статуси, команди
db.py       — замовлення й позиції в SQLite, статистика
config.py   — налаштування, каталог (docs/data/products.json — єдине джерело цін)
docs/       — вітрина (також на GitHub Pages)
panel/      — адмінка
```
